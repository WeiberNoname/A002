## 📤 4. Uploading to Steam

### Method A: SteamPipe GUI (Easiest)
1. Download the official **SteamPipe GUI** from the Steamworks documentation or SDK.
2. Set **App ID** and **Depot ID** (usually `AppID + 1`).
3. Set the **Content Root Directory** to:
   ```
   C:\Users\space\.gemini\antigravity-ide\scratch\Daysome-Project-T1000-V1 Ready\DesktopPet-win32-x64
   ```
4. Enter your Steam developer credentials and click **Upload**.

---

### Method B: SteamCMD (Automated CLI)

1. Create a depot build configuration file `depot_build.vdf`:
```vdf
"DepotBuildConfig"
{
    "DepotID" "YOUR_DEPOT_ID"
    "ContentRoot" "C:\Users\space\.gemini\antigravity-ide\scratch\Daysome-Project-T1000-V1 Ready\DesktopPet-win32-x64"
    "FileMapping"
    {
        "LocalPath" "*"
        "DepotPath" "."
        "recursive" "1"
    }
    "FileExclusion" "*.pdb"
}
```

2. Create an app build configuration file `app_build.vdf`:
```vdf
"AppBuild"
{
    "AppID" "YOUR_APP_ID"
    "Desc" "Initial Release v1.0.0"
    "BuildOutput" "C:\Users\space\steam_build_output"
    "ContentRoot" "C:\Users\space\.gemini\antigravity-ide\scratch\Daysome-Project-T1000-V1 Ready\DesktopPet-win32-x64"
    "SetLive" "default"
    "Depots"
    {
        "YOUR_DEPOT_ID" "depot_build.vdf"
    }
}
```

3. Run SteamCMD:
```cmd
steamcmd.exe +login <your_steam_account> +run_app_build app_build.vdf +quit
```

## 🖼️ 6. Steam Store Presence Requirements

Before your store page can go live, Valve requires:
1. **Capsule Images**:
   * Header Capsule: `460 x 215`
   * Small Capsule: `231 x 87`
   * Main Capsule: `616 x 353`
   * Vertical Capsule: `374 x 448`
2. **Screenshots**: At least 5 screenshots (`1920 x 1080`) showing the 3D companion, animated stickers, desktop pinned memos, and chat HUD.
3. **14-Day "Coming Soon" Requirement**: Valve requires your store page to be approved and visible as **Coming Soon** for at least 14 days before the public purchase button can be enabled.
